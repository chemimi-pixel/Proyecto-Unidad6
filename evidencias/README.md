# Evidencias de presentacion

Guardar aqui capturas o un video breve de la demostracion real del lector de codigos de barras. Incluir el lector conectado, la lectura que inicia una busqueda y la operacion asociada en la aplicacion.

No guardar aqui archivos `.env`, contrasenas, hashes de contrasena ni credenciales MySQL. Aun no se incluye evidencia porque el lector fisico debe probarse en el equipo de presentacion.
